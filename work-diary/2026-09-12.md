## Notes

**Decisions locked today** (all now written up in `CLAUDE.md`, which is the source of truth — this
is just the trail):

- Next.js App Router + TypeScript on Vercel, React Three Fiber + drei for the 3D. Godot and Unity
  considered and rejected: wasm payload size, flaky iOS Safari, and the content is text panels over
  a 3D scene, which is DOM's job.
- **The scene is a document; edits are a diff over an immutable OSM baseline; the editor is the
  viewer plus a layer.** The failure mode to watch for is ever building a second renderer.
- September non-goals, written down so they stay decided: no terrain, no free-roam avatar, no auth
  / uploads / database.
- **Three licences, not one.** Code MIT, OSM-derived `baseline` ODbL, authored 2045 content
  CC BY-SA 4.0. A blanket MIT would have misstated the terms the moment generated OSM data landed
  in the repo, because ODbL is share-alike and cannot be relicensed. The root `LICENSE` stays pure
  MIT so GitHub's detector still reads it; the split lives in the README table.
- **Assets go in the repo, not Git LFS.** LFS complicates Vercel builds, is metered on public
  repos, and would undermine the offline static export the exhibition machine depends on. The perf
  budget is the size discipline instead — anything too big for git was already too big for a phone.
  Authoring sources (`.blend`, `.fbx`, `.psd`) are ignored; optimised `.glb` is committed.
- **The OSM cache is ignored; the generated scene document is committed.** Same reasoning as
  `docs/architecture.md`: the exhibition must not depend on Overpass being up.
